# Information Retrieval in High Dimensional Data

## Overview

From **face recognition** to **gene data analysis**, and from analyzing **motor sensor data** to describing **human body motion**, engineers often face the challenge of working with **high-dimensional data**—data acquired from numerous sensors. A crucial step in extracting meaningful information from this vast amount of data is to **reduce its dimensionality** intelligently, which is also essential for effectively **visualizing** high-dimensional datasets.

This course starts with an overview of applications and introduces a basic method of dimensionality reduction, **Principal Component Analysis (PCA)**. It then delves into modern methods and their fields of application.

---

## Topics Covered

- **Decisions from Data**
- **Curse of Dimensionality**
- **From Phenomena to Data**
- **Logistic Regression**
- **Principal Component Analysis (PCA)**
- **Linear Discriminant Analysis (LDA)**
- **Support Vector Machines (SVM)**
- **Kernel PCA**
- **Feedforward Neural Networks**

---

## Learning Outcomes

By the end of this course, students will:

- Understand several **state-of-the-art dimensionality reduction** and **data analysis techniques**.
- Be capable of **implementing these techniques in Python**.
- Apply methods in **image processing** and **natural language processing** tasks, providing paradigms for analyzing high-dimensional data.

In addition to technical skills, the lab course offers students opportunities to:
